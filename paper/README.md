# Camera-ready paper

Two-page summary for the NeurIPS 2026 Education Track, in the official `neurips_2026.sty` template with the `education, final` options and no checklist.

- `cut_neurips2026_education.pdf`: the camera-ready PDF
- `cut_neurips2026_education.tex`: LaTeX source
- `neurips_2026.sty`: the unmodified NeurIPS 2026 style file

Build with `pdflatex cut_neurips2026_education.tex` (run twice for references), or `tectonic cut_neurips2026_education.tex`.
